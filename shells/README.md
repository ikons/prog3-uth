# Κελύφη του Unix

Συνοδευτικά σκριπτ της διάλεξης 4 «Τα κελύφη του Unix». Οι διαφάνειες δείχνουν
αποσπάσματα από αυτά ακριβώς τα αρχεία.

| Αρχείο | Τι δείχνει |
|---|---|
| `script.sh` | το πρώτο σκριπτ: στο bash το `echo -n` δεν αλλάζει γραμμή |
| `script.ksh` | το ίδιο στο Korn shell, με `\c` (στο Dockerfile υπάρχει το `ksh`) |
| `script2.sh` | `$0`, `$1`, `$*`, `$$` και ένα προσωρινό αρχείο· στη διαφάνεια λέγεται `script.sh`, όπως στο βιβλίο |
| `letter.sh` | here document (`<< ENDOFTEXT`) με μεταβλητές |

```bash
./script.sh
./script2.sh paul ringo
./letter.sh tim
```

Το `script2.sh` τυπώνει το δικό του όνομα με το `$0`, άρα `./script2.sh` αντί
για το `./script.sh` των διαφανειών.
