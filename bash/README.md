# Το κέλυφος Bash

Συνοδευτικά σκριπτ της διάλεξης 8 «Το κέλυφος Bourne Again (bash)». Οι
διαφάνειες δείχνουν αυτά ακριβώς τα αρχεία· τα σχήματα σύνταξης (`if`, `case`,
`for`, `while`, `until`) μένουν στις διαφάνειες. Δοκιμάστηκαν με GNU bash 5.2 σε
Debian 13.

Πολλά σκριπτ αλλάζουν αρχεία: τρέξτε τα σε έναν δοκιμαστικό κατάλογο. Αυτά που
γράφουν έξω από τον τρέχοντα κατάλογο:

- `trash.sh` και `old.sh` μετακινούν αρχεία στους `~/trash` και `~/old`
  (το `old.sh` τα κάνει και μόνο για ανάγνωση).
- `backup.sh` γράφει `~/backup-ΗΜΕΡΟΜΗΝΙΑ.tar.gz` με τον `~/work`.
- `symlinks.sh` προσθέτει γραμμές στο `~/symlinks.list`.
- `trash1.sh` αντιγράφει όλα τα αρχεία του τρέχοντος καταλόγου στον `trash` και
  μετά τον σβήνει· `lower.sh` μετονομάζει σε πεζά όλα τα αρχεία του τρέχοντος
  καταλόγου (ρωτά πριν αντικαταστήσει).

| Σκριπτ | Τι δείχνει |
|---|---|
| `check.sh` | ποια `*.sh` είναι εκτελέσιμα (`[ -x ]`) |
| `hello.sh`, `hello2.sh` | το πρώτο σκριπτ· μια μεταβλητή |
| `trash1.sh` | εντολές του τερματικού σε σκριπτ |
| `delete.sh` | `read` και `rm -i` |
| `backup.sh` | αντικατάσταση εντολής, `$(date +%F)` |
| `arithmetic.sh` | αριθμητική με `$(( ))` |
| `user.sh`, `number.sh`, `and.sh` | `if`, φωλιασμένα `if`, `&&` |
| `fstab.sh` | έλεγχος αρχείου `-f` (το «Παράδειγμα» των διαφανειών) |
| `iftrue.sh` | μια εντολή ως συνθήκη (`if cd "$x"`) |
| `sparameters.sh` | `$#`, `$0`, `$1`, `$*`, `$@` |
| `trash.sh` | ένας κάδος ανακύκλωσης |
| `case.sh`, `case2.sh` | `case` με μία τιμή ανά κλάδο, και με μοτίβο `[1-9]` |
| `sum.sh`, `for.sh`, `for1.sh` | `for` με λίστα, και χωρίς `in` |
| `old.sh`, `args.sh` | `"$@"` και `"$*"` |
| `for2.sh`, `for3.sh` | `for (( ))`· το ίδιο με `bash -x` |
| `while.sh`, `countdown.sh` | `while`, `until` |
| `menu.sh` | μενού με `while`, `read -s` και `case` |
| `grepedit.sh` | `shift` και `$?`: ανοίγει στον `vi` τα αρχεία που περιέχουν ένα μοτίβο |
| `continue.sh`, `break.sh` | `continue`, `break` |
| `symlinks.sh` | οι συμβολικοί σύνδεσμοι ενός καταλόγου |
| `func.sh`, `function.sh` | συναρτήσεις και `return` |
| `card.sh`, `cardstats.sh` | πίνακες και `$RANDOM`· το `cardstats.sh` θέλει το `bc` |
| `lower.sh` | ονόματα αρχείων σε πεζά (`tr`, `mv -i --`) |
| `compare.sh` | `cmp` και ο κωδικός εξόδου του |

```bash
./hello.sh
printf '7\n3\n' | ./arithmetic.sh
./args.sh a "b c"
./cardstats.sh 100000
```
